# Rasf

The Rasf studio, in two parts:

- **`web/`**: the public website at [rasf.studio](https://rasf.studio). Astro, Arabic first with English at `/en/`.
- **`dashboard/`**: the admin dashboard for the site's content. React + Vite + Firebase; manages blog posts so far. See its README to connect it to Firebase.
- **`brand/`**: the source logo artwork, shared by both.

Each part is its own project with its own `package.json`; run its commands from inside its folder.
